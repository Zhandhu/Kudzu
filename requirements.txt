# Kudzu: what you need to run it
#
# This is a JavaScript project, so this file is for people to read. It is not a
# pip file. The packages below are installed by `npm install`, which reads
# package.json and the exact versions pinned in package-lock.json.
#
# 1. Install Node.js 20 or newer (npm comes with it): https://nodejs.org
# 2. In this folder, run:   npm install
# 3. Then run:              npm run dev
#    and open the address it prints (http://localhost:5173 by default).
#
# Nothing else needs installing: there is no backend, database or API key.
# All data is mocked and kept in the browser.
#
# An internet connection is needed while the app runs, for two things that are
# loaded from the web and not bundled:
#   - the fonts (Google Fonts: Fraunces and Inter)
#   - the map tiles on the Network tab (OpenStreetMap)
# Without one the app still works; text falls back to system fonts and the map
# background is blank.
